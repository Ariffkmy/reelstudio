Soalan lazim

Sebelum anda beli

Adakah saya perlu bayar setiap video?

Tidak kepada kami. Penulisan dan pembinaan menggunakan had langganan Claude anda sendiri. Render, suara AI dan B-roll percuma berjalan tanpa kredit. ElevenLabs atau model imej berbayar hanya jika anda pilih untuk gunakannya.

Boleh guna akaun Claude percuma?

Tidak. Reel Studio bergantung pada Claude Code, yang datang bersama pelan Pro atau Max. Setiap reel menggunakan banyak kerja, jadi Max memberi ruang lebih jika anda buat banyak reel.

Adakah Reel Studio produk Anthropic?

Bukan. Reel Studio ialah aplikasi bebas yang menjalankan Claude Code di komputer anda. Anda log masuk ke Claude sendiri, dan penggunaan Claude dibilkan terus oleh Anthropic di bawah pelan anda.

Ada versi Mac?

Belum. Versi pertama untuk Windows 10 dan 11. Pembeli akan dimaklumkan bila versi Mac siap.

Boleh guna untuk klien atau jenama saya?

Ya. Reel Studio tidak menuntut apa-apa hak atas video yang anda hasilkan. Untuk B-roll dan muzik stok, ikut syarat lesen setiap sumber; Reel Studio menyimpan senarai kredit dalam setiap projek.

Berapa lama satu reel?

Pelan siap dalam kira-kira seminit. Selepas anda luluskan, pembinaan mengambil 15–30 minit dan render beberapa minit, bergantung pada komputer. Anda boleh tinggalkan ia berjalan.

Reel Studio ialah aplikasi bebas dan tidak bergabung dengan Anthropic. Claude dan Claude Code ialah tanda dagangan Anthropic, PBC.

Dibina dengan alat sumber terbuka: HyperFrames (HeyGen), opencut-motion dan animate (lesen MIT), Whisper, Kokoro.
